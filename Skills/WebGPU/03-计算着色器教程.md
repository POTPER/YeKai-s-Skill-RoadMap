# WebGPU 计算着色器示例和教程

## 什么是计算着色器？

计算着色器（Compute Shader）是 WebGPU 的一个强大功能，允许你利用 GPU 的并行处理能力进行通用计算。与传统的图形渲染不同，计算着色器专门用于：

- **并行数据处理**: 同时处理大量数据
- **科学计算**: 矩阵运算、物理模拟
- **图像处理**: 滤镜、特效、图像分析
- **机器学习**: 神经网络计算
- **游戏逻辑**: 粒子系统、碰撞检测

## 核心概念

### 工作组（Workgroups）
- **工作组大小**: 例如 `@workgroup_size(64)` 表示每个工作组包含 64 个线程
- **调度**: `dispatchWorkgroups(8)` 创建 8 个工作组，总共 512 个线程
- **全局 ID**: `@builtin(global_invocation_id)` 获取当前线程的全局索引

### 存储缓冲区
- **读写访问**: `var<storage, read_write> data: array<f32>`
- **只读访问**: `var<storage, read> input: array<f32>`
- **数据传输**: CPU 和 GPU 之间的数据交换

## 实际应用示例

### 1. 数组操作
```wgsl
@compute @workgroup_size(64)
fn main(@builtin(global_invocation_id) global_id: vec3<u32>) {
    let index = global_id.x;
    if (index >= arrayLength(&data)) {
        return;
    }
    
    // 每个元素乘以 2
    data[index] = data[index] * 2.0;
}
```

### 2. 图像处理
```wgsl
@compute @workgroup_size(8, 8)
fn main(@builtin(global_invocation_id) global_id: vec3<u32>) {
    let coord = vec2<i32>(global_id.xy);
    let dimensions = textureDimensions(inputTexture);
    
    if (coord.x >= dimensions.x || coord.y >= dimensions.y) {
        return;
    }
    
    // 应用高斯模糊滤镜
    var color = vec4<f32>(0.0);
    for (var y = -2; y <= 2; y++) {
        for (var x = -2; x <= 2; x++) {
            let sampleCoord = coord + vec2<i32>(x, y);
            let weight = gaussianWeights[abs(x)][abs(y)];
            color += textureLoad(inputTexture, sampleCoord, 0) * weight;
        }
    }
    
    textureStore(outputTexture, coord, color);
}
```

### 3. 物理模拟
```wgsl
struct Particle {
    position: vec2<f32>,
    velocity: vec2<f32>,
    mass: f32,
}

@compute @workgroup_size(64)
fn main(@builtin(global_invocation_id) global_id: vec3<u32>) {
    let index = global_id.x;
    if (index >= arrayLength(&particles)) {
        return;
    }
    
    var particle = particles[index];
    
    // 应用重力
    particle.velocity.y += -9.81 * deltaTime;
    
    // 更新位置
    particle.position += particle.velocity * deltaTime;
    
    // 边界碰撞
    if (particle.position.y < 0.0) {
        particle.position.y = 0.0;
        particle.velocity.y *= -0.8; // 反弹衰减
    }
    
    particles[index] = particle;
}
```

## 性能优化技巧

### 1. 工作组大小优化
- **GPU 架构相关**: 现代 GPU 通常以 32 或 64 为倍数效率最高
- **内存访问模式**: 相邻线程访问相邻内存效率更高
- **共享内存**: 利用工作组内的共享内存减少全局内存访问

### 2. 内存访问优化
```wgsl
// 好的模式：连续访问
let index = global_id.x;
data[index] = data[index] * 2.0;

// 避免的模式：跨步访问
let index = global_id.x * stride; // stride 很大时效率低
```

### 3. 分支优化
```wgsl
// 尽量避免复杂的分支
if (condition) {
    // 简单操作
} else {
    // 简单操作
}

// 使用 select 函数代替简单分支
let result = select(valueA, valueB, condition);
```

## 调试技巧

### 1. 数据验证
```javascript
// 检查输入数据
console.log('输入数据:', input);

// 检查输出数据
await resultBuffer.mapAsync(GPUMapMode.READ);
const result = new Float32Array(resultBuffer.getMappedRange());
console.log('输出数据:', result);
```

### 2. 工作组调度验证
```javascript
const workgroupSize = 64;
const dataSize = input.length;
const numWorkgroups = Math.ceil(dataSize / workgroupSize);

console.log(`数据大小: ${dataSize}`);
console.log(`工作组大小: ${workgroupSize}`);
console.log(`工作组数量: ${numWorkgroups}`);
```

### 3. 性能测量
```javascript
const startTime = performance.now();

// 执行计算着色器
device.queue.submit([commandEncoder.finish()]);

// 等待完成
await device.queue.onSubmittedWorkDone();

const endTime = performance.now();
console.log(`计算时间: ${endTime - startTime}ms`);
```
