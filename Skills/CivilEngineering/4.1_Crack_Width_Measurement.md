4.  **CECS 21:2000《超声法检测混凝土缺陷技术规程》** (参考)

## 3. 工程背景与原理 (Background & Theory)

### 3.1 物理原理
*   **传统光学法**: 利用刻度显微镜（通常放大倍率 40x-100x），将裂缝边缘成像在分划板上。读数原理基于几何光学放大，公式为 $W = N \times K$，其中 $W$ 为宽度，$N$ 为格数，$K$ 为每格代表的实际长度（需标定）。
*   **数字图像处理法 (AI)**:
    *   **像素当量标定**: $R = L_{ref} / P_{ref}$ (mm/pixel)，利用已知尺寸的参照物（如Tag码）计算像素物理尺寸。
    *   **边缘检测**: 使用 Canny 算子或 Sobel 算子提取裂缝边缘。
    *   **亚像素算法**: 通过灰度矩或插值算法，将检测精度提升至 0.1 像素级别。

### 3.2 适用场景
*   **构件**: 混凝土梁（受弯/受剪裂缝）、楼板（收缩/角部裂缝）、剪力墙、柱。
*   **状态**: 表面清洁，无覆盖层（如腻子、涂料需清理）。

## 5. 标准操作流程 (Standard Operating Procedure)

### 步骤 1: 现场调查与选点 (Survey & Selection)
1.  **目测普查**: 对构件进行全数目测，绘制裂缝分布草图。
2.  **选点原则**:
    *   每条裂缝至少选取 3 个测点（起点、中点、终点）。
    *   **关键点**: 必须包含目测裂缝宽度最大处。
    *   对于受力裂缝（如梁底跨中），应加密测点。
3.  **编号**: 采用 "构件号-裂缝号-测点号" 格式（例: L1-C1-P1）。

### 步骤 2: 表面处理 (Surface Preparation)
1.  使用钢丝刷或砂纸清理测点区域的灰尘、油污、疏松层。
2.  **注意**: 严禁损伤混凝土骨料，仅去除表面装饰层或风化层，露出原状裂缝。
3.  对于暗裂缝，可喷洒酒精辅助显影（利用润湿角差异）。

### 步骤 3: 仪器测量 (Measurement)

#### 3.1 裂缝显微镜法 (Primary Method)
1.  **调焦**: 将显微镜垂直置于裂缝表面，打开光源，调节旋钮直至刻度线与裂缝边缘均清晰。
2.  **对齐**: 旋转目镜，使刻度尺垂直于裂缝走向。
3.  **读数**: 读取裂缝两侧边缘在刻度尺上的截距，计算宽度。
4.  **记录**: 记录读数至 0.01mm。

#### 3.2 AI 智能识别法 (Smart Method)
1.  **贴标**: 在裂缝旁粘贴标准参照贴（Tag）。
2.  **拍摄**: 开启APP，保持手机镜头与裂缝面平行，距离约 5-10cm，确保裂缝与Tag同框且对焦清晰。
3.  **识别**: 等待APP自动勾勒裂缝轮廓并计算宽度。
4.  **截图**: 保存带有测量数据的图片作为原始凭证。

### 步骤 4: 数据校核与记录 (Verification)
*   **比对**: 若 AI 读数与显微镜读数偏差 > 10% 或 > 0.05mm，以显微镜读数为准，并重新拍摄。
*   **记录表**: 填写《混凝土裂缝宽度检测记录表》。

## 6. 数据分析与评估 (Analysis & Evaluation)

### 6.1 数据统计
*   计算每条裂缝的**最大宽度 ($W_{max}$)** 和 **平均宽度 ($W_{avg}$)**。
*   绘制裂缝分布图，标注超限区域。

### 6.2 结果判定 (Decision Gate)
依据 GB 50344 及设计要求进行判定（以下为典型限值，具体依设计文件）：

| 环境类别 | 钢筋混凝土结构裂缝控制等级 | 最大裂缝宽度限值 $W_{lim}$ (mm) | 判定结论 |
| :--- | :--- | :--- | :--- |
| **一类 (室内干燥)** | 三级 | 0.30 | $W \le 0.30$: 合格 (Pass)<br>$W > 0.30$: 不合格 (Fail) |
| **二a类 (室内潮湿)** | 三级 | 0.20 | 同上 |

*   **[Risk Warning]**: 若 $W_{max} > 0.5mm$ 或出现贯通裂缝，应立即启动结构安全性鉴定程序。

### 6.3 误差分析 (Uncertainty Analysis)
*   **人为误差**: 读数时的视差（Parallax Error）。
*   **仪器误差**: 显微镜刻度漂移（需定期送检）。
*   **环境误差**: 表面粗糙度导致的光影误判。
*   **AI算法误差**: 图像模糊、光照不均、参照物变形导致的像素当量计算偏差。

### 附录代码: Python OpenCV 裂缝宽度估算示例

```python
import cv2
import numpy as np

def estimate_crack_width(image_path, pixel_scale):
    """
    估算裂缝宽度
    
    Args:
        image_path: 图片路径
        pixel_scale: 像素标定因子 (mm/pixel), 需通过参照物获取
        
    Returns:
        max_width_mm: 最大宽度 (mm)
    """
    # 1. 读取图像并转换为灰度图
    # Engineering Rationale: 裂缝通常比混凝土表面颜色深，灰度化简化了计算维度
    img = cv2.imread(image_path)
    if img is None:
        raise ValueError("Image not found")
    gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)

    # 2. 图像预处理 (高斯滤波)
    # Engineering Rationale: 混凝土表面存在骨料斑点噪声，滤波可减少误判
    blurred = cv2.GaussianBlur(gray, (5, 5), 0)

    # 3. 边缘检测 / 阈值分割 (Otsu's Method)
    # Engineering Rationale: Otsu算法自动寻找最佳阈值，适应不同光照条件
    _, binary = cv2.threshold(blurred, 0, 255, cv2.THRESH_BINARY_INV + cv2.THRESH_OTSU)

    # 4. 形态学操作 (闭运算)
    # Engineering Rationale: 连接断开的裂缝片段
    kernel = np.ones((3,3), np.uint8)
    closing = cv2.morphologyEx(binary, cv2.MORPH_CLOSE, kernel)

    # 5. 轮廓提取
    contours, _ = cv2.findContours(closing, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
    
    max_width_px = 0
    
    # 6. 宽度计算 (基于距离变换)
    # Engineering Rationale: 计算二值图中前景像素到最近背景像素的距离，
    # 距离变换图中的最大值即为裂缝最大半径，宽度 = 2 * 半径
    dist_transform = cv2.distanceTransform(closing, cv2.DIST_L2, 5)
    max_radius_px = np.max(dist_transform)
    max_width_px = max_radius_px * 2

    # 7. 物理量转换
    max_width_mm = max_width_px * pixel_scale
    
    return max_width_mm

# 使用示例
```
