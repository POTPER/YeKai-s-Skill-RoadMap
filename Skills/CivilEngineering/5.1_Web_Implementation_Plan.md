# 砖混结构沉降裂缝实训 Web 产品技术落地建议

基于 [5.1_Practical_Training_Case.md](./5.1_Practical_Training_Case.md) 的实训流程，结合您提出的 SVG 动画方向，我为您构思了一套完整的 Web 技术落地与实现方案。

## 1. 核心技术栈推荐 (Tech Stack)

为了实现高交互性和流畅的动画演示，建议采用以下技术组合：

*   **前端框架**: **React** 或 **Vue 3** (构建单页应用，管理实训步骤状态)。
*   **动画引擎 (核心)**: **GSAP (GreenSock Animation Platform)**。
    *   *理由*: 它是目前控制 SVG 动画最强大的库。可以精确控制时间轴 (Timeline)，完美实现“降水 -> 地基变形 -> 墙体开裂”的因果序列动画。
*   **交互绘图 (关键)**: **Konva.js** 或 **Fabric.js**。
    *   *理由*: 实训中包含“裂缝测绘”和“监测布点”操作，纯 SVG 操作 DOM 性能较差且逻辑复杂，Canvas 库（如 Konva）能提供更好的拖拽、绘图和层级管理体验。
*   **UI 组件库**: **Ant Design** 或 **Element Plus** (用于侧边栏、任务面板、表单控件)。

## 2. 各实训环节的具体实现方案

### 环节一：情景复现 (Case Scenario) - 沉降机理动画
**目标**: 展示“基坑降水导致不均匀沉降”的过程。

*   **表现形式**: 2.5D 剖面视角的 SVG 动画。
*   **技术实现**:
    1.  **SVG 分层绘制**: 将“土层”、“地下水”、“建筑物”、“基坑”绘制为独立的 SVG Group (`<g>`)。
    2.  **GSAP 动画编排**:
        *   **水位下降**: 使用 GSAP 动画控制水面 Path 的 `d` 属性或 `transform: translateY`。
        *   **土体固结**: 配合水位下降，压缩土层的高度。
        *   **建筑变形**: 使用 GSAP 的 `MorphSVGPlugin` (或简单的 `skew`/`rotate`) 模拟建筑物东侧下沉。
        *   **裂缝生长**: 预先在墙体上画好裂缝路径 (Path)，设置 `stroke-dasharray` 和 `stroke-dashoffset`。当沉降达到阈值时，通过动画减小 `offset` 值，实现裂缝“生长”出来的效果。
*   **交互点**: 提供一个“时间滑块”或“播放按钮”，让学生自己拖动进度，观察不同沉降量下的裂缝变化。

### 环节二：裂缝测绘 (Crack Mapping) - 交互绘图
**目标**: 在立面图上徒手绘制裂缝并标注。

*   **表现形式**: 类似画板的交互界面。
*   **技术实现**:
    *   **底图**: 将建筑立面 SVG 作为 **Konva.js** 的背景图层。
    *   **绘图工具**:
        *   利用 Konva 的 `Line` 形状实现“自由画笔”功能（监听 `mousemove` 事件采集点坐标）。
        *   提供“撤销/重做”栈 (History Stack)。
    *   **判定逻辑**:
        *   后端存储标准答案的裂缝区域（多边形热区）。
        *   计算学生绘制的线条与热区的重叠率 (Intersection)，自动判断“绘制位置是否准确”。

### 环节三：成因推演 (Reasoning) - 拖拽拼图/选择
**目标**: 区分“正八字”与“倒八字”的力学模型。

*   **表现形式**: 交互式原理图。
*   **技术实现**:
    *   **SVG 交互**:
        *   左侧提供“中间沉降”和“端部沉降”两个地基变形图标（可拖拽）。
        *   右侧提供“上部受拉”和“下部受拉”的应力云图。
    *   **逻辑**: 使用 **HTML5 Drag and Drop API** 或 **React-DnD**。学生需要将正确的沉降模式拖入场景，如果匹配正确，触发 SVG 动画演示该模式下的受力变形，并高亮对应的裂缝形态。

### 环节四：监测方案 (Monitoring) - 模拟布点
**目标**: 在平面图/立面图上布置监测点。

*   **表现形式**: 拖拽组件到地图上。
*   **技术实现**:
    *   **组件库**: 准备“沉降观测点”（符号▲）和“裂缝观测点”（符号⧈）的 SVG 图标。
    *   **Canvas 交互 (Konva.js)**:
        *   学生从工具栏拖拽图标到建筑图纸上。
        *   **吸附功能**: 设置关键节点（如墙角、柱基）的磁吸范围，辅助学生精准布点。
    *   **验证**: 提交时，遍历 Canvas 上的所有点位坐标，检查关键位置（如东山墙角、裂缝两侧）是否覆盖。

## 3. 进阶体验：引入 Three.js (可选)

如果预算充足且追求视觉冲击力，可以将“环节一”升级为 **Web 3D**。

*   **Three.js / React-Three-Fiber**:
    *   建立简易的 3D 楼房模型和基坑模型。
    *   材质贴图：给墙面贴上带有裂缝纹理的贴图。
    *   **优势**: 学生可以 360 度旋转观察建筑，更直观地看到“东侧沉降”的空间关系。
    *   **劣势**: 开发成本高，且对于“裂缝形态”这种平面几何特征的教学，3D 有时反而不如 2D 剖面清晰。

## 4. 总结与建议

对于**工程实训类** Web 产品，**“SVG + GSAP + Konva.js”** 是性价比最高的黄金组合：

1.  **SVG** 保证了工程图纸的专业性和清晰度（无限缩放不失真）。
2.  **GSAP** 提供了极具表现力的原理演示动画。
3.  **Konva.js** 解决了复杂的绘图和交互需求。

您可以先从一个简单的 **MVP (最小可行性产品)** 开始：做一个基于 SVG 的“沉降原理演示器”，验证 GSAP 动画对教学效果的提升。
