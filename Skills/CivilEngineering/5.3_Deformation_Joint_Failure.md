## 1. 教学目标 (Learning Objectives)

*   **概念区分**: 明确伸缩缝（温度）、沉降缝（不均匀沉降）、防震缝（地震）的功能差异与构造要求。
*   **病害识别**: 能够辨别变形缝的功能性失效（如止水带破损、内填材料老化）与结构性破坏（如缝宽不足导致的挤压撞击）。
*   **规范应用**: 依据 GB 50010、GB 50003 和 GB 50011 判定缝宽是否合规，使用 GB 50292 进行安全性评级。
*   **处置方案**: 掌握清理、置换填缝材料及止水带修复的标准化工艺。

## 3. 工程背景与机理 (Background & Mechanism)

### 3.1 变形缝分类
*   **伸缩缝 (Expansion Joint)**: 应对温度变化和混凝土收缩，断开上部结构，基础可不断开。
*   **沉降缝 (Settlement Joint)**: 应对地基不均匀沉降，从基础到屋顶全部断开。
*   **防震缝 (Seismic Joint)**: 防止地震时体型复杂结构的不规则振动破坏，需有足够宽度。

### 3.2 失效机理
变形缝的病害通常属于 **“先天缺陷”** 或 **“耐久性失效”**：
1.  **缝宽不足 (Design/Construction Defect)**: 设计时未考虑足够的抗震间距，或施工时模板跑模导致缝宽变窄，导致热胀或地震时两侧结构发生 **“硬碰硬”** 挤压破坏。
2.  **异物卡阻 (Debris Blockage)**: 施工建筑垃圾（混凝土块、砖渣）落入缝内，使本应自由变形的结构被“卡死”，导致墙体或梁端开裂。
3.  **填料老化 (Material Aging)**: 沥青麻丝、聚苯板等填充材料老化、脱落，或橡胶止水带腐蚀断裂，导致 **雨天渗漏** 和风化加速。
4.  **不均匀沉降 (Uneven Settlement)**: 若沉降量超过沉降缝的设计余量，会导致缝两侧出现较大的 **错台 (Vertical Offset)**，撕裂防水层。

## 4. 典型特征与识别 (Identification)

| 特征维度 | 表现描述 |
| :--- | :--- |
| **位置** | 伸缩缝两侧、沉降缝处、新旧建筑连接处。 |
| **形态** | **缝边破损**: 混凝土剥落、露筋。<br>**错台**: 缝两侧楼地面高低不平。<br>**挤压**: 装饰盖板变形、起拱。 |
| **动态性** | **周期性开合**: 随气温变化（热胀时缝变窄，冷缩时缝变宽）。<br>**渗漏**: 雨天缝口有明显水迹或滴水。 |
| **伴随症状** | 室内对应位置的墙角出现垂直裂缝或45度斜裂缝（因变形受阻引起）。 |

## 5. 标准化鉴定流程 (Assessment Workflow)

### 步骤一：外观检查 (Visual Inspection)
1.  **测量缝宽**: 检查实际缝宽是否满足 GB 50011 要求（如框架结构高度<15m时，缝宽不应小于100mm）。
2.  **检查内部**: 使用内窥镜或长焦镜头观察缝内是否有**建筑垃圾**堵塞。
3.  **检查错台**: 测量缝两侧的垂直高差，判断是否存在严重的不均匀沉降。

### 步骤二：监测方案 (Monitoring)
针对疑似活动的病害，需布置监测：
*   **监测指标**: 缝宽变化量 ($\Delta W$)、垂直沉降差 ($\Delta H$)。
*   **设备**:
    *   **游标卡尺/测缝计**: 定期人工测量。
    *   **自动化位移计**: 连续记录，结合气温/降雨数据分析。
*   **判据**:
    *   若 $\Delta W$ 随气温呈现规则的正弦波变化，说明伸缩功能正常。
    *   若 $\Delta W$ 持续减小（单向闭合），警惕结构倾斜或滑移。
    *   若 $\Delta H$ 持续增加，说明地基沉降未稳定。

### 步骤三：安全性评级 (Rating)
*   **cu/du 级 (危险)**:
    *   缝内严重堵塞导致两侧构件受压破坏（压溃、主筋屈服）。
    *   沉降缝两侧高差过大，导致上部结构连接构件（如连廊）濒临坠落。
*   **Au/Bu 级 (正常/轻微)**:
    *   仅有盖板变形或轻微渗漏，结构主体完好。

## 6. 处理与维修方案 (Treatment & Retrofit)

### 6.1 清理与疏通 (Cleaning)
*   **对象**: 存在硬物卡阻的变形缝。
*   **工艺**: 拆除表面装饰层 -> 使用长钎或高压水枪清除缝内混凝土块、砖渣 -> 确认缝隙全高贯通。

### 6.2 止水修复 (Waterproofing Repair)
*   **方案**: 针对渗漏问题。
*   **工艺**:
    1.  **清理基面**: 铲除老化填料，打磨缝壁。
    2.  **设置背衬**: 塞入聚乙烯泡沫棒（Backer Rod），控制密封胶深度。
    3.  **注胶密封**: 注入耐候硅酮密封胶或聚氨酯密封胶。
    4.  **增设止水带**: 对于地下室或屋面，可加贴外贴式橡胶止水带（E型或Ω型）。

### 6.3 恢复构造功能 (Function Restoration)
*   **盖板修复**: 更换变形的金属盖板，采用 **滑移式连接**（一端固定，一端长孔滑动），确保不限制结构变形。
*   **结构加固**: 若因缝宽不足导致构件压溃，需剔除部分混凝土扩大缝宽，并对受损构件进行碳纤维或粘钢加固。

## 7. 案例快查表 (Quick Reference)

| 核心问题 | 关键特征 | 处理原则 |
| :--- | :--- | :--- |
| **垃圾卡阻** | 缝两侧墙体开裂，缝内可见硬物 | **彻底清理**，释放约束 |
| **缝宽不足** | 地震/高温时发生碰撞，混凝土压碎 | **剔凿扩缝**，满足抗震要求 |
| **止水失效** | 缝口渗水，内墙发霉 | **重做密封**，增设止水带 |
| **不均匀沉降** | 缝两侧明显错台 | 监测沉降，**纠偏**或结构托换 |
