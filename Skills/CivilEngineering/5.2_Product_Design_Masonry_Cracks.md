# 产品化设计方案：砌体结构温度裂缝智能诊治系统 (Product Design: Smart Masonry Crack Diagnosis System)

> **设计背景**: 基于《5.2 砌体结构温度裂缝》工程案例，将静态的工程知识转化为动态的数字化产品功能，服务于房屋安全鉴定机构、物业管理方及维修工程队。

## 1. 产品定位 (Product Positioning)

*   **核心价值**: **“专家经验数字化”** —— 将资深工程师识别温度裂缝的经验（位置、形态、动态性）固化为算法逻辑，降低鉴定门槛，提高定性准确率。
*   **目标用户**:
    *   **一线巡检员**: 缺乏深度理论，需要“傻瓜式”判定工具。
    *   **鉴定工程师**: 需要高效的数据整理和报告生成工具。
    *   **业主/物业**: 需要直观的风险提示和维修建议。

## 2. 核心功能架构 (Core Architecture)

我们将文档中的知识点映射为四大核心模块：

### 2.1 智能诊断模块 (Intelligent Diagnosis)
> **转化点**: 文档 3.2 节“典型特征” & 4.1 节“现场勘查”

*   **特征提取向导 (Wizard)**:
    *   *Q1*: 裂缝位置？ (选项：**顶层** / 中间层 / 底层) -> *[权重++]*
    *   *Q2*: 裂缝形态？ (拍照上传 + AI识别 或 选项：**倒八字** / 水平 / 垂直 / X形) -> *[权重++]*
    *   *Q3*: 屋面情况？ (选项：**平屋顶无保温** / 坡屋顶 / 有隔热层)
*   **判定引擎**:
    *   **规则**: IF (Location == "顶层" AND Shape == "八字/水平") THEN "温度裂缝可能性 > 90%".
    *   **排他逻辑**: 提示检查是否有基础沉降迹象（排除法）。

### 2.2 规范合规引擎 (Compliance Engine)
> **转化点**: 文档 第2章“规范依据” & 4.3 节“安全性评级”

*   **数字化标尺**:
    *   内置 **GB 50292-2015 第 5.4.6 条** 判据。
    *   输入：裂缝最大宽度 ($W_{max}$)、裂缝数量。
*   **自动评级**:
    *   IF ($W_{max} > 5.0mm$) OR (墙体通长裂缝) -> **Alert Level: Red (cu/du级)** -> 触发“立即停止使用/加固”建议。
    *   IF ($W_{max} < 1.5mm$) -> **Alert Level: Blue (Bs/Cs级)** -> 触发“持续监测”建议。

### 2.3 IoT 动态监测中心 (IoT Monitoring Hub)
> **转化点**: 文档 3.1 节“机理” & 4.2 节“监测”

*   **温-宽相关性分析**:
    *   接入数据：表面温度传感器 ($T$) + 数字裂缝计 ($W$)。
    *   **算法**: 计算皮尔逊相关系数。若 $W$ 与 $T$ 呈现显著负相关（气温升裂缝闭，气温降裂缝开），系统自动判定为**“活动性温度裂缝”**。
*   **趋势预测**: 基于历史气温数据，预测下一个寒潮来临时裂缝可能的张开宽度。

### 2.4 维修方案生成器 (Solution Generator)
> **转化点**: 文档 第5章“处理方案”

*   **决策树**:
    *   分支1: 裂缝宽度 < 0.2mm -> 推荐 **“表面封闭法”** (生成材料清单：弹性涂料)。
    *   分支2: 裂缝宽度 > 1.0mm (活动) -> 推荐 **“填充密封法”** (生成材料清单：PU密封胶、背衬泡沫棒)。
    *   分支3: 评级为 cu/du -> 推荐 **“结构加固”** (生成图纸模板：钢筋网复合砂浆)。
*   **SOP 推送**: 直接在 App 端展示文档中 5.2 节的施工步骤（清理 -> 开槽 -> 填缝 -> 挂网）。

## 3. 用户旅程地图 (User Journey Map)

1.  **发现 (Discover)**: 巡检员在顶层发现裂缝，打开 App。
2.  **采集 (Capture)**: 拍摄裂缝照片，App 自动识别为“倒八字形”，自动获取当前楼层（GPS/气压计辅助）。
3.  **定性 (Analyze)**: App 提示“高度疑似温度裂缝”，并要求测量宽度。
4.  **定量 (Measure)**: 输入宽度 3.2mm。系统比对 GB 50292，判定为“尚不影响承载，但需处理”。
5.  **决策 (Decide)**: 系统推荐“柔性填充修补方案”，并生成 PDF 简报。
6.  **闭环 (Close)**: 维修完成后，上传修复照片，系统归档。

## 5. 商业化亮点 (USP)

1.  **合规性背书**: 所有判定逻辑均锚定国家标准（GB），生成的报告具有法律效力参考价值。
2.  **避免过度维修**: 精准区分“活动裂缝”与“静止裂缝”，避免对活动裂缝使用刚性砂浆修补导致的“修了又裂”，降低返修率。
3.  **教育属性**: 在工单执行过程中，向工人推送标准工艺（如“必须开U型槽”），提升施工质量。
