# 工程检测虚拟仿真教学系统设计 (Virtual Simulation System Design for Education)

> **核心转变**: 从“生产工具”转向“教学工具”。
> **设计目标**: 让学生在**零风险、低成本**的虚拟环境中，通过**“试错”**来掌握规范操作流程（SOP）和判读逻辑。

## 1. 系统定位与教学逻辑

不同于生产环境追求“效率与防伪”，教学环境追求的是：
1.  **情境感 (Context)**: 还原真实的工程现场环境（如：高空、暗光、噪音）。
2.  **交互性 (Interaction)**: 让学生亲手操作（如：长按鼠标模拟钻孔），而不是简单填数。
3.  **容错性 (Fail-Safe)**: 允许犯错，并展示错误后果（如：没清孔就滴酚酞 -> 显色模糊 -> 扣分）。

## 2. 虚拟数据工厂 (Virtual Data Factory)

既然是仿真，数据就不是“采”来的，而是**“生成”**出来的。我们需要一个**“随机病害生成引擎”**。

### 2.1 场景生成器 (Scenario Generator)
学生开始练习时，系统随机生成一个“考题包”：
*   **场景 A (正常)**: 新建住宅，C30混凝土，干燥环境。
    *   *后台生成真值*: 碳化深度=0mm，保护层=25mm。
*   **场景 B (危房)**: 50年老厂房，酸性环境，潮湿。
    *   *后台生成真值*: 碳化深度=35mm (严重超标)，保护层=20mm，伴有钢筋锈胀裂缝。

### 2.2 虚拟仪器交互 (Virtual Instruments)

我们用软件模拟硬件的物理反馈。

| 真实步骤 | 生产 App 操作 | **仿真系统交互设计** | 教学考察点 |
| :--- | :--- | :--- | :--- |
| **1. 钻孔** | 填钻孔深度 | **长按鼠标钻孔**。<br>- 按时间累积深度。<br>- *随机事件*: 碰到钢筋（手柄震动/声音刺耳），若不停止 -> 钻头损坏 (Game Over)。 | 避筋意识、钻孔深度控制 |
| **2. 清孔** | (默认已做) | **拖动“洗耳球”工具**。<br>- 若跳过此步直接滴液 -> 屏幕显示“粉末浑浊”，无法读数 -> 强制重做。 | 规范流程 (JGJ/T 23) |
| **3. 滴液** | (默认已做) | **点击滴管**。<br>- 动画显示液体渗入孔壁。<br>- *颜色渲染*: 根据“真值”渲染紫红色/灰色边界。 | 试剂用量、润湿程度 |
| **4. 测量** | 蓝牙自动填 | **虚拟卡尺读数**。<br>- 屏幕弹出放大的孔洞剖面图和游标卡尺。<br>- 学生需**拖动游标**对齐变色界限，手动输入读数。 | 读数精度、视差消除 |

## 3. 教学评分模型 (Scoring Model)

系统不再是简单的“合格/不合格”，而是给学生的行为打分。

*   **操作规范分 (40%)**:
    *   漏做“清孔”步骤：-10分。
    *   钻孔碰到钢筋未停机：-20分。
    *   滴液后未等待显色立即读数：-5分。
*   **数据准确分 (30%)**:
    *   学生读数 vs 系统真值。误差 $\le 0.5mm$ 得满分，否则按偏差扣分。
*   **诊断结论分 (30%)**:
    *   基于自己读出的数据，能否得出正确的结论（如：判定为“钢筋锈蚀风险高”）。

## 4. 界面架构调整 (UI Adaptation)

### 4.1 3D 漫游视图 (The Viewport)
*   **主视口**: 第一人称视角（FPS），在虚拟工地中行走。
*   **构件高亮**: 鼠标悬停在梁/柱上，显示“待检测”。

### 4.2 工具腰带 (Toolbar)
*   屏幕下方常驻工具栏：电锤、洗耳球、酚酞瓶、深度尺、记录本。
*   **操作逻辑**: 拖动工具到构件上触发互动。

### 4.3 虚拟平板 (Virtual Pad)
*   按 `Tab` 键呼出。
*   这就是我们之前设计的 **"通用检测 App"** 的虚拟版！
*   **联动**: 学生在 3D 场景里测量出的数据，需要**手动**录入到这个虚拟 Pad 里（模拟真实工作中“测完记下来”的过程）。

## 5. 总结

对于**虚拟仿真教学**，核心不在于“数据怎么传”，而在于**“数据怎么造”**和**“过程怎么演”**。

*   **数据源**: 不再是蓝牙/二维码，而是**“随机题库算法”**。
*   **核心价值**: 让学生在虚拟世界里把该犯的错都犯一遍（比如钻坏钻头、读错数、误判风险），这样到了真实工地才不会出事故。
