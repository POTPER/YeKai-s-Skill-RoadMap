# 2D 交互式仿真教学方案 (2D Interactive Simulation Design)

> **设计思路**: 摒弃沉重的 3D 漫游，采用 **"定点全景图 + 交互式插画"** (Point & Click) 的形式。
> **类比**: 类似《机械迷城》或《锈湖》的点击解谜游戏。

## 1. 界面布局 (Layout)

```text
+-------------------------------------------------------+
|  [顶部] 任务目标：请对 3 层 柱子 C-2 进行碳化检测        |
+--------------------------+----------------------------+
|                          |                            |
|      (主视口 - Canvas)    |      (侧边栏 - App)        |
|                          |                            |
|   展示工程现场的 2D 画面   |    虚拟检测记录表单         |
|   (SVG / 图片)           |    (输入数据、判定结果)      |
|                          |                            |
|   [交互热点]: 梁、柱、墙   |    [提交按钮]               |
|                          |                            |
+--------------------------+----------------------------+
|  [底部工具栏 - Inventory]                               |
|  [电锤] [洗耳球] [酚酞瓶] [深度尺] [回弹仪]              |
+-------------------------------------------------------+
```

## 2. 交互逻辑 (Interaction Flow)

### 场景一：宏观选点
*   **画面**: 一张建筑立面图或室内照片。
*   **操作**: 鼠标悬停在构件上，构件边缘发光（SVG Stroke 高亮）。
*   **逻辑**: 点击“柱子 C-2”，镜头推近，进入“微观操作视角”。

### 场景二：微观操作 (The Micro-Lab)
这是核心教学区，通过 **"拖拽 (Drag & Drop)"** 实现仿真。

#### 步骤 1: 钻孔
*   **画面**: 混凝土表面特写。
*   **操作**: 拖动底部工具栏的 **[电锤]** 到画面中心。
*   **反馈**:
    *   *动画*: 播放钻孔 GIF 或 Canvas 粒子效果（飞出粉末）。
    *   *音效*: 电钻声。
    *   *结果*: 画面上出现一个灰色的圆孔。

#### 步骤 2: 清孔 (关键考点)
*   **操作**: 拖动 **[洗耳球]** 到圆孔上点击。
*   **反馈**: 动画显示粉末被吹散，孔洞变干净。
*   **分支逻辑**:
    *   若**未做**此步直接进行下一步 -> 系统记录“违规操作”。

#### 步骤 3: 滴液显色
*   **操作**: 拖动 **[酚酞瓶]** 到孔洞。
*   **反馈**:
    *   孔洞内壁颜色发生变化。
    *   *Canvas 绘制*: 根据后台真值（如碳化 8mm），绘制一个**外圈灰色、内圈紫红色**的同心圆（或不规则形状）。
    *   *随机性*: 边缘可以做一些噪点处理，模拟真实的参差不齐。

#### 步骤 4: 测量读数
*   **操作**: 拖动 **[深度尺]**。
*   **反馈**:
    *   屏幕上出现一个**可拖动的游标卡尺控件**。
    *   学生需要用鼠标拖动卡尺的“测针”，对齐那个“紫红/灰色”的分界线。
    *   卡尺上的数字（或刻度）会随拖动变化。
*   **记录**: 学生看准了刻度，在右侧的 App 表单里输入读数。

## 3. 技术实现方案 (Web Tech Stack)

### 方案 A: Canvas API (推荐)
*   **优势**: 像素级控制，适合绘制“滴液扩散”、“显色边界”等动态效果。
*   **实现**:
    *   底图是混凝土纹理。
    *   `ctx.globalCompositeOperation = 'source-over'` 绘制紫红色层。
    *   `ctx.globalCompositeOperation = 'destination-out'` 根据碳化深度擦除外圈，露出灰色的底色。

### 方案 B: SVG + CSS
*   **优势**: 矢量高清，交互简单（DOM 事件），适合做卡尺、工具拖拽。
*   **实现**:
    *   卡尺是一个 SVG Group (`<g>`)。
    *   通过 Vue/React 绑定 `mousedown/mousemove` 事件控制 SVG 的 `transform` 属性。

## 4. 2D 仿真的优势

1.  **开发成本低**: 不需要 3D 建模师，找几张照片修一下图，或者画点 SVG 矢量图就能做。
2.  **运行流畅**: 纯网页，不吃显卡，手机/平板也能玩。
3.  **教学聚焦**: 3D 漫游容易让学生晕头转向（“我在哪？”），2D 视角固定，学生只能关注“怎么操作”。

这就像是把《植物大战僵尸》的玩法套用到了工程教学上：**场景探索 + 道具解谜**。
