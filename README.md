# 规则

# 对话记录管理规范

## 1. 完整记录要求
- **全量保存**：完整记录对话全生命周期数据
  - 用户原始提问文本（含修改历史）
  - AI生成回复的所有版本
  - 对话过程中的上下文补充
  - 思考过程记录（包含推理链条）
  - 错误修正轨迹
  - 外部资源引用
- **存储位置**：统一归档至`/Notes/`目录
- **版本控制**：使用Git管理文件变更历史
  - 每次修改必须提交
  - 提交信息包含修改原因
  - 分支管理策略：主题分支+合并主线

## 2. 文件命名体系
- **标准格式**：`YYYY-MM-DD_HH-mm_提问人_AI模型_主题关键词.md`
- **示例**：`2025-09-03_22-33_YeKai_Claude-Sonnet-4_对话记录范例.md`
- **扩展规则**：
  - 系列对话：添加序号后缀`_Part01`
  - 紧急记录：添加`_URGENT`标识
  - 草稿状态：添加`_DRAFT`标识
  - 审核状态：添加`_REVIEW`标识
  - 归档状态：添加`_ARCHIVED`标识
- **时间规范**：
  - 24小时制时间戳
  - 精确到分钟级
  - 时区统一为UTC+8
  - 夏令时自动调整

## 3. 内容结构标准
### 元信息头部
- **必填字段**：
  - 提问时间（ISO 8601格式）
  - 提问人身份标识
  - AI模型及版本号（包含训练截止日期）
  - 主题标签（#前缀，至少3个层级）：
    - 领域标签：#技术/#商业/#设计
    - 子领域标签：#前端开发/#用户研究
    - 技术标签：#React/#用户画像
  - 对话类型（学习/工作/创作/研究/咨询）
- **可选字段**：
  - 前置知识依赖
  - 关联对话索引
  - 预期输出类型
  - 优先级标记（P0-P4）

### 对话主体
- **对话轮次**：使用`##`二级标题分隔
- **问题标注**：`###`三级标题+问题摘要
- **AI回复结构**：
  - 理解确认（重述用户需求）
  - 思考过程（推理步骤）
  - 核心回答（主要内容）
  - 补充说明（延伸思考）
  - 下一步建议（行动指导）
- **格式要求**：
  - 保留原始分段结构
  - 突出显示关键结论
  - 代码块保持语法高亮
  - 图表使用Mermaid语法

### 尾部总结
- **核心要点**（3-5条）
- **知识收获**（新学习内容）
- **行动项**（具体可执行任务）
- **疑问点**（需要进一步探索）
- **关联资源**（相关链接和文档）
- **文件状态标识**：
  - ✅ 完整（FINALIZED）
  - ⚠️ 待续（IN_PROGRESS） 
  - 🔄 更新中（UPDATING）
  - ✏️ 草稿（DRAFT）
  - 🔍 审核中（REVIEW）
  - 🗄️ 已归档（ARCHIVED）

## 4. 视觉呈现规范
- **基础格式**：标准Markdown语法
- **样式控制系统**：
  - 严格遵循STYLE2.CSS设计语言
  - 响应式布局适配（移动端优先）
  - 暗色模式自动切换
  - 无障碍访问支持
- **组件样式映射**：
  - 代码块：`glass-card`毛玻璃效果
  - 引用块：`sensor-card`传感器风格
  - 列表项：阶梯式缩进+hover动效
  - 标题：渐变色+阴影效果
  - 链接：悬浮预览+平滑过渡

## 5. 对话流程管理
- **分类标准**：
  - **微对话**（1轮）：快速问答，单一主题
  - **短对话**（2-3轮）：单文件存储，`---`分隔
  - **中对话**（4-10轮）：分章节组织，建立内部导航
  - **长对话**（＞10轮）：拆分文件，建立索引系统
- **连续性管理**：
  - 对话链式引用
  - 上下文传承标记
  - 话题演进追踪
  - 结论收敛分析

## 6. 数据保全机制
- **多层备份策略**：
  - **实时备份**：每次保存自动同步
  - **本地备份**：每周五17:00完整镜像
  - **云端备份**：每月1日增量备份
  - **异地备份**：每季度灾难恢复测试
- **完整性验证**：
  - 文件哈希校验（SHA-256）
  - 元数据一致性检查
  - 结构完整性验证
  - 内容可读性测试
- **恢复机制**：
  - 自动故障检测
  - 一键恢复功能
  - 版本回滚支持
  - 数据修复工具

## 7. 安全防护体系
- **隐私保护矩阵**：
  - **敏感信息识别**：自动检测PII数据
  - **分级脱敏处理**：根据敏感级别掩码
  - **访问权限控制**：角色基础授权（RBAC）
  - **审计追踪**：完整操作日志
- **加密安全方案**：
  - **传输加密**：TLS 1.3协议
  - **存储加密**：AES-256-GCM算法
  - **密钥管理**：HSM硬件安全模块
  - **身份验证**：多因子认证（MFA）

## 8. 智能知识管理
- **多维标签体系**：
  - **主题标签**：技术领域分类（3级结构）
  - **类型标签**：问答/教学/讨论/创作/咨询
  - **难度标签**：L1初级/L2中级/L3高级/L4专家
  - **时效标签**：时间敏感/长期有效/周期性
  - **质量标签**：未验证/已验证/专家认证
- **知识图谱构建**：
  - **实体抽取**：自动识别关键概念
  - **关系建模**：语义关联分析（包含5种关系类型）
  - **图谱更新**：增量学习机制（每日自动更新）
  - **可视化展示**：交互式网络图（支持3D模式）
- **智能推荐引擎**：
  - **内容推荐**：基于历史偏好+知识图谱
  - **学习路径**：个性化课程规划（含难度曲线）
  - **知识补全**：识别认知盲区（基于图谱分析）
  - **质量评估**：多维度评分系统（5个评估维度）

## 9. 协作与共享机制
- **团队协作**：
  - **权限分级**：查看/编辑/管理/所有者权限
  - **协同编辑**：实时多人协作（支持冲突检测）
  - **变更通知**：自动消息推送（分级提醒）
  - **冲突解决**：智能合并算法（保留修改意图）
- **知识共享**：
  - **公开发布**：脱敏后社区分享（支持多种格式）
  - **模板库**：标准化模板管理（版本控制）
  - **最佳实践**：优秀案例收集（含评审机制）
  - **学习社区**：专业交流平台（集成知识图谱）

## 10. 质量控制与持续改进
- **质量评估框架**：
  - **完整性检查**：必填字段验证（自动化扫描）
  - **一致性审核**：格式标准化检查（正则表达式）
  - **准确性验证**：事实查证机制（多源比对）
  - **可用性测试**：用户体验评估（A/B测试）
- **持续改进机制**：
  - **定期回顾**：月度质量分析报告（可视化仪表盘）
  - **用户反馈**：意见收集与处理（闭环管理）
  - **流程优化**：工作流程持续改进（PDCA循环）
  - **技术升级**：工具链定期更新（季度评估）
