# YeKai-s-Skill-RoadMap
YeKai's Skill RoadMap History!




# 规则

1. 所有我与AI的对话（包括问题与AI的完整回复）都需记录在Notes文件夹中。
2. 每个问题与答案需单独保存为一个文件，文件名应包含提问时间、提问人、所用大模型名称，便于检索与归档。
3. 文件内容需包括：
   - 提问时间（精确到分钟）
   - 提问人姓名或昵称
   - 所用AI大模型名称及版本
   - 问题内容
   - AI的完整回复
4. 文件格式建议为Markdown（.md），并遵循 STYLE2.CSS 的风格规范，确保页面美观统一。
5. 若有多轮对话，建议每轮对话单独成文件，或在文件内清晰分隔每轮内容。
6. 定期备份Notes文件夹，防止数据丢失。
7. 严禁在文件中泄露个人隐私或敏感信息，注意数据安全。
8. 鼓励对有价值的对话进行标签分类，便于后续查找与整理。
